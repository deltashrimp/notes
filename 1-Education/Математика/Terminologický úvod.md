# Operatory

| Operace                                          | Nazvá               |                                             |
| ------------------------------------------------ | ------------------- | ------------------------------------------- |
| $a+b$                                            | sčítání, součet     |                                             |
| $a-b$                                            | odčítání, rozdíl    |                                             |
| $a \times b$                                     | krát, násobení      |                                             |
| $a : b$                                          | děleno, dělení      |                                             |
| $a / b$                                          | lomeno              |                                             |
| $\frac{a}{b}$                                    | zlomek              | $b \neq 0$, $a$ - čitatel, $b$ - jmenovatel |
| $\sqrt{a}$                                       | odmocnina           | $á$-tá odmocnina z $b$                      |
| $a^b$                                            | exponent            | $a$ na $b$ (-ou)                            |
| $=$                                              | rovnítko, rovná se  |                                             |
| $\neq$                                           | nerovná se          |                                             |
| $a < b$                                          | je menší            |                                             |
| $a > b$                                          | je větší            |                                             |
| $a \leq b$                                       | je menší nebo rovno |                                             |
| $a \geq b$                                       | je větší nebo rovno |                                             |
| $\frac{3}{7} \times \frac{9}{9} = \frac{27}{63}$ | rozšíření           |                                             |
| $\frac{27}{63} = \frac{3}{7}$                    | zkrácení            |                                             |

| Operace   | Перевод    |
| --------- | ---------- |
| rozšíření |            |
| zkrácení  | сокращение |
| řazeni    | сортировка |
